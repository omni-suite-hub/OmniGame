# 🎮 OmniGame — 小游戏合集盒

一个 **Chrome MV3 浏览器扩展**：离线优先、支持局域网雷达与房间密钥 WebRTC 联机对战、响应式自适应的本地小游戏合集。
所有游戏以 `iframe` 隔离加载，互不污染 CSS / JS；进度、战绩与天梯分写入 `chrome.storage.local`。

> 内置 8 款高品质小游戏：
> - 🪐 **重力方阵**（自研翻转下棋 · 局域网/跨网联机 + 智能 AI + 本地双人）
> - ⚔️ **方块死斗**（双人俄罗斯方块死斗 · 实时攻防互顶垃圾行）
> - 🎲 **暗箱轮盘**（恶魔轮盘风赛博对决 · 实弹虚弹概率与心理博弈）
> - 🟦 **2048**（经典数字滑动合成 · 大屏自适应）
> - 🐍 **贪吃蛇**（经典反应成长避障 · 大屏自适应）
> - 💣 **扫雷**（经典邻域推导 · 大屏自适应）
> - 🧱 **俄罗斯方块**（单人经典消行升级 · 大屏自适应）
> - ⭕ **画个完美的圆**（自研签名 toy · 手绘几何评分）

## ✨ 特性

- **WebRTC 双模多人联机**：支持同一 Wi-Fi 下“局域网雷达自动发现”与“6 位房间密钥跨网直连”，数据 P2P 直达（延迟 < 5ms）。
- **免发版热插拔**：`OmniCatalog` 架构支持从云端清单或动态 URL 加载新游戏，无需重新打包插件。
- **天梯与战绩持久化**：内置 Elo 天梯分机制与近 50 场对局战报，数据写入 `chrome.storage.local`。
- **全屏响应式自适应**：游戏窗口拉大或全屏打开自动等比舒展充满，摆脱小窗束缚。
- **悬浮球与双模小窗**：普通网页支持内嵌拖拽小窗，受限页面自动无缝降级独立桌面小窗，100% 成功弹窗。
- **离线优先**：经典核心游戏 100% 零依赖单机秒开。

## 🚀 如何加载（3 步）

1. 打开 Chrome，访问 `chrome://extensions`。
2. 右上角打开 **开发者模式 (Developer mode)**。
3. 点击 **加载已解压的扩展程序 (Load unpacked)**，选择本仓库根目录 `OmniGame/`。
   完成后点击工具栏拼图图标 → **OmniGame** 即可弹出启动器。

> 提示：弹窗尺寸受 Chrome 限制（约几百像素）。若想在大屏（如 1280px）完整体验，
> 在启动器点任意游戏右上角的 **↗** 可在新标签页全屏打开该游戏。

## 🖥️ 本地静态预览（无需安装扩展）

扩展页面在 `file://` 下无法运行（Chrome 限制），但可用静态服务器预览 UI 与游戏逻辑：

```bash
cd OmniGame
python3 -m http.server 8080
# 浏览器打开：
#   启动器: http://localhost:8080/popup.html
#   单游戏: http://localhost:8080/games/2048/index.html  （同理替换 2048 为其他游戏 id）
```

> 注意：本地预览下 `chrome.storage` 不可用，代码会自动降级到 `localStorage` 保存分数。

## ✅ 手动自测清单

**加载**
- [ ] `chrome://extensions` 加载未打包扩展无报错；`manifest.json` 合法。
- [ ] 点击工具栏图标弹出启动器；卡片网格正常显示，最佳分显示 `—` 或历史值。

**离线 / 无外链**
- [ ] 断网状态下所有游戏可正常打开并游玩。
- [ ] 见下方“离线化验证”命令，确认全局无 `http(s)://`、CDN、外域引用。

**响应式**
- [ ] 视口 360px：启动器 2 列卡片，游戏可操作（滑动 / 屏幕按钮有效）。
- [ ] 视口 1280px（新标签打开）：启动器多列铺满，游戏 `iframe` 自适应放大。

**持久化**
- [ ] 玩一局后返回启动器，对应卡片“最佳”分数已更新。
- [ ] 完全关闭弹窗再打开，最佳分仍在（写入 `chrome.storage.local`）。

**隔离**
- [ ] 反复在游戏间切换，未出现样式串色或脚本报错（iframe 各自独立）。

**各游戏**
- [ ] 2048：方向键 / WASD / 滑动可合并；出现 2048 弹“你赢了”，可继续；无路可走弹“游戏结束”。
- [ ] 贪吃蛇：方向键 / 屏幕方向键 / 滑动可控；吃苹果加分加速；撞墙或自身结束。
- [ ] 扫雷：初级/中级/高级可切换；首点必安全；左键翻开、右键/长按/标雷模式插旗；踩雷/通关弹窗。
- [ ] 俄罗斯方块：← → 移动、↑ 旋转、↓ 软降、空格硬降、P 暂停；消行计分升级；预览下一个。
- [ ] 画个完美的圆：画完整圆松手评分；显示百分比与分享文案；复制按钮可用；再画一次可重来。
